# OmnishPilot brand

**One line:** Wake to proof, not hope.

**WHY:** Heavy work should finish while you sleep — and you should wake to proof, not hope.  
**HOW:** Own the *outcome* of unattended agent work on your machine.  
**WHAT:** OmnishPilot — free local autonomy harness.

## Voice

| Use | Avoid |
|-----|--------|
| babysitting → finished work | feature laundry (sandbox, bwrap, YOLO…) |
| green ≠ done / proof not hope | “AI-powered”, “next-gen”, “seamless” |
| close the laptop | jargon-first demos |
| free · local · yours | waitlists, cloud lock-in |

## Mark

The logo is an **instrument plate**: tilted dark hull, cyan incomplete orbit (work in motion), ice chevron (forward), orange beacon (morning signal).

| File | Use |
|------|-----|
| `logo.svg` / `logo-512.png` | App, npm, GitHub, favicon source |
| `icon-master.jpg` | Social avatar / app icon master |
| `og.jpg` | Open Graph, Show HN, Reddit link preview |
| `wordmark.svg` | Horizontal lockups |

## Color

| Token | Hex | Role |
|-------|-----|------|
| Hull | `#0a2230` → `#020814` | Primary dark |
| Orbit | `#00e5ff` / `#7af0ff` | Motion / trust |
| Beacon | `#ff8a2b` | Morning / alert / CTA spark |
| Ice | `#d8f6ff` | Chevron / type on dark |

Do not default to purple gradients or cream-serif “AI startup” looks.

## Public discussion kit

1. Lead with the morning after, not the scheduler.  
2. One install line: `npm i -g omnishpilot`  
3. Attach `og.jpg` / logo — not a screenshot wall.  
4. Ask for breakage reports (sandbox on Mac/Windows, overnight CI).  
5. See `docs/outreach-reddit.md` and `docs/video-script.md`.

## Dev OS (product, not marketing)

Unattended coding jobs ship with a distilled **Dev operating system** inside the OmnishPilot skill (`skills/omnishpilot/references/`). That is part of the product promise — agents finish with confidence — not a slogan. Keep marketing language free of “dev skill” jargon; show the feeling: plan → build → `result.md` proof.
