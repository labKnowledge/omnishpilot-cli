# OmnishPilot — video script

**Use:** product promo / launch cut  
**Length:** ~50s hero · 15s short · optional 90s  
**Tone:** calm authority, not hype. Short sentences. Silence is a beat.  
**Rule:** sell the morning after — never list features.

---

## Positioning (read once, then film)

| | |
|--|--|
| **WHY** | Heavy work should finish while you sleep — and you should wake to proof, not hope. |
| **Market noise** | “Schedule agents.” “Autopilot.” “Cloud routines.” Everyone sells the *trigger*. |
| **Our gap** | Nobody owns the *outcome*: did it actually finish, alone, on your machine, without babysitting. |
| **One line** | Stop babysitting agents overnight. Wake up to finished work. |

**Do not say on camera:** sandbox, failover, webhooks, verifier, bubblewrap, YOLO, CLI flags.  
**Show those as feelings:** laptop closed · night clock · morning pack · file that exists · “done.”

## Production notes

### Music
Low pulse, industrial-calm or soft synth — not epic trailer. Drop almost silent on “green ≠ done,” swell on “wake to a verdict.”

### Captions
Burn in the on-screen column; keep VO and captions aligned. Punch words: **babysitting**, **proof**, **done**.

### B-roll that sells value (not UI chrome)
1. Night → morning time jump  
2. Approval dialog nobody answered  
3. Green check next to empty output  
4. Notification that reads like a human verdict  
5. One real artifact opening  

Avoid: scrolling settings, architecture diagrams, CLI flag lists, “10 features” kinetic type.

### End card (2s hold)
```
OmnishPilot
Wake up to done.
npm i -g omnishpilot
github.com/labKnowledge/omnishpilot-cli
```

### Alternate CTAs (same energy)
- “Install free. Run local.”
- “Your overnight shift — without the babysitting.”
- “When green isn’t enough.”
